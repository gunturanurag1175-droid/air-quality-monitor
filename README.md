# air-quality-monitor
Portable ESP32-based air quality monitoring system

## Project Files

- `air-quality-monitor.yaml` - ESPHome firmware configuration.
- `secrets.yaml.example` - Template for local Wi-Fi, API, and dashboard secrets.
- `docs/` - Project documents, reports, diagrams, datasheets, and notes.
- `prototype-videos/` - Prototype demo videos and testing clips.

## Adding Documents And Videos

Keep project documents in `docs/` and prototype videos in `prototype-videos/`.

Recommended video formats: `.mp4` or `.mov`. If a video is very large, upload it through GitHub Releases or Git LFS instead of committing it directly.
