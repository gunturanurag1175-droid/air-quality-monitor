# Project Documents

Use this folder for documents related to the air quality monitor project.

Good files to keep here:

- Project report
- Circuit diagram
- Block diagram
- Component list
- Sensor datasheets
- Presentation slides
- Setup or testing notes

Suggested naming:

- `project-report.pdf`
- `circuit-diagram.png`
- `component-list.xlsx`
- `testing-notes.md`
